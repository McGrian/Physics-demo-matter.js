2D Physics Tetris-ish Demo

Files:
- index.html — main page
- style.css — layout and grid
- main.js — Matter.js physics and interactions

How to run:
1. Open `index.html` in a browser (double-click or `open index.html`).
2. Drag a piece from the left sidebar into the play area (canvas).
3. While dragging, press `R` to rotate. Release mouse to drop and enable physics.
4. After placement, you can click and drag pieces with the mouse.

Notes:
- This is a simple demo using Matter.js from CDN. You can extend pieces, add scoring, or implement snapping constraints to enforce a strict Tetris grid and row-clearing logic.
